# **App Name**: AgriShare

## Core Features:

- Role-Based User Management: Secure authentication and authorization system to manage Admin, Investor, Manager, and Employee roles, ensuring appropriate access to features and data.
- Interactive Dashboard: A centralized dashboard providing key financial (investments, revenues, expenses, profits) and production metrics (eggs, mortality) tailored to each user role, with simple visualizations.
- Dynamic Investment & Share Management: Track investor contributions, automatically calculate and update dynamic ownership percentages, and provide a clear history of all investments.
- Farm Accounting & Transaction Management: Record, categorize, and manage all income (egg sales, chicken sales) and expenses (feed, medication, salaries), offering a complete financial overview with filtering capabilities.
- Poultry Production Tracking: Allow employees to input daily data for egg production and mortality. The system tracks the total number of chickens and automatically calculates key production metrics.
- AI-Powered Performance Insights & Alerts: An AI tool that analyzes production and financial data, identifying potential issues like significant drops in production or rises in mortality, and providing smart suggestions for improvement or cost savings.
- Transparent Reporting & Data Export: Generate essential financial and operational reports (e.g., investment summaries, income/expense reports) and enable easy export in PDF or Excel format for full transparency.

## Style Guidelines:

- Primary color: A grounded and professional green (#3B9941), symbolizing growth and agriculture, used for key actions and branding elements. (Based on 'vert (agriculture)').
- Background color: A very light, desaturated green (#F3F9F4) to ensure a clean, bright, and simple interface, enhancing readability and visual clarity.
- Accent color: A vibrant golden yellow (#E6BF19) to highlight financial data, important alerts, and calls to action, drawing inspiration from the user's mention of 'jaune (finance)'.
- Font: 'Inter' (sans-serif) for all text. Its modern, highly readable, and neutral characteristics ensure clarity and simplicity across both mobile and web interfaces, aligning with the 'simple, claire' directive.
- Utilize a consistent set of simple, clean line icons that are easily recognizable and reinforce the intuitive navigation, in line with the 'icônes simples' request.
- Mobile-first, clean, and uncluttered layout with clear content hierarchy. The primary navigation includes 'Dashboard', 'Investissements', 'Comptabilité', 'Production', 'Bénéfices', and 'Profil', optimized for quick access and ease of use on smaller screens.
- Subtle and functional animations to provide visual feedback for user actions and smooth transitions between screens, ensuring the application remains 'rapide' and unobtrusive without 'surcharger l’interface'.
